### 实际颜色

浏览器 computed 色检查（透明背景按实际白色单元格合成）：手工/未知风险为暖灰（5.78:1）；高风险为深红（5.49:1）；陈价、未知成本与过期为棕色（5.10:1）。近期转多/转空/新增关注继续实心强调和方向文字，对比分别 5.35/5.18/6.76:1。以上小字对比均 ≥4.5:1。

未迁移页面 Element 实心主按钮已有深色 hover 机制，保留合理浅色阶。观察清单 NVDA 链接 hover 确实曾落到浅色阶（2.92:1）；局部 `--el-link-hover-text-color` 修复后实际为 rgb(142,69,49)，白底约 6.89:1。没有为该调用点修改整组浅色阶。

## 缺陷、修复与复验

| 观察到的缺陷 | 最小修复 | 受影响复验 |
|---|---|---|
| 桌面竖线过重、搜索框过宽、报价来源重复占行 | 恢复库行分隔、搜索收窄、币种/日期行作为来源触发器 | 七尺寸新截图 |
| 1024 摘要 2×2 占用过多高度，手机小计重复挡住明细 | 1024 实际大金额四列；手机默认市场/占比、原位 details 展开细项；收紧重复留白 | 七位金额实际测量；375/393 首屏及展开图 |
| 加载错误与空数据混淆，深链误判未持有 | 复用 `loadError` 分支遮蔽汇总/数量/小计，移动/桌面空态一致，深链等待成功 | 新增桌面/手机加载→失败→重试真实控件回归 |
| 表头 `aria-sort` 在键盘切换后滞后 | 局部 watch/nextTick 与库 DOM 更新同步 | 排序、账户视图、移动再回桌面 |
| 日期控件不支持 `input-props`，名称未落到输入框 | 使用控件公开 placeholder 名称，账户用可搜索输入名称 | 实际转仓/本地日期/弹窗键盘焦点 |
| 迁移漏掉近期观点的实心强调 | 按既有 effect 映射实心颜色，棕色文字/白字对比成立 | 分析状态回归和展示样例 computed/截图 |
| 手机价格按钮触控面积过小、其他页链接 hover 太浅 | 局部按钮高度；链接仅修 hover 文字变量 | 独立六尺寸与真实观察清单 computed 核验 |
| warning 标签同色 12% 背景上小字对比仅 4.43:1 | 仅 `Tag.textColorWarning` 深为 #875a21，保留原背景/图标/实心观点 | 实际透明背景合成后的状态对比与新截图 |
| 口径说明在 320px 开启后撑宽至 427px，375/393px 左侧正文裁切 | 使用 NPopover 公开数字 width、手机 bottom-end 与局部视口宽度上限；≤360px 沿既有单列布局使用 220px，保留全文和库 flip | 一个新增真实键盘回归覆盖 320/375/393 四边与页面宽度；独立 demo 另复验 768/1440；根独立复验 320/360/361/375/393/768/1440 全部四边、全文、宽度与键盘开关通过。来源/事件未越界且转手机后卸载，未修改它们 |
| 旧 E2E 依赖 Element 持仓 DOM、旧字号或 hover 行为 | 仅更新持仓相关选择器/公开名称和已批准字号；新 popover 经过真实 click | 全量结果与受影响文件复验，未降低金融断言 |
