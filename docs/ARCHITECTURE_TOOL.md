# 本地代码结构浏览

架构浏览器是本仓库的独立开发工具，不需要启动投资系统或连接业务数据库。它读取允许的源码和工程文件，展示目录、依赖及原始源码位置。

## 安装和启动

在仓库根目录创建独立 Python 3.12 环境，安装分析器和现有前端开发依赖：

```sh
python3.12 -m venv .venv-architecture
.venv-architecture/bin/python -m pip install -r tools/architecture/requirements.txt
npm --prefix frontend ci
make architecture
```

已有 uv 时，第一步也可以使用 `uv venv --python 3.12 .venv-architecture`。首次安装需要网络；安装完成后的静态分析和页面浏览不需要网络。

服务默认监听 `0.0.0.0:8765`，不自动打开浏览器。在本机打开 `http://127.0.0.1:8765`，或从同一局域网的其他设备访问 `http://<本机局域网 IP>:8765`。停止时在启动终端按 Ctrl+C。端口被占用时启动失败，不会停止其他服务；可直接使用下列命令选择另一个端口：

```sh
.venv-architecture/bin/python -m tools.architecture.server --port 8766
```

如只需本机访问，显式指定回环监听地址：

```sh
.venv-architecture/bin/python -m tools.architecture.server --host 127.0.0.1
```

## 浏览

从项目目录进入模块与文件，使用关系图及依赖列表查看引用和被引用的位置；文件与符号搜索可以直接进入源码。源码只读，点击函数、类或依赖行可定位。

图形区域可切换“关系图”和“UML 图”。UML 采用固定分层布局，以 package/module 方框和虚线依赖箭头展示同一份索引；箭头从引用方指向被引用方，数字是合并的导入证据数。可从“后端模块”或“前端模块”进入主要源码目录，再继续下钻。这里的方框代表目录或文件，不推断类继承、运行时调用或前后端请求链；现有关系图和源码证据仍可使用。UML 使用本地打包的 [Mermaid](https://mermaid.js.org/syntax/classDiagram)，不向外部绘图服务发送源码。

索引代表一次源码快照。编辑后使用“重新扫描”；如果已索引文件发生变化，源码接口会返回过期提示，避免把新源码与旧图混在一起。分析提示会说明未解析的范围，不能把没有可靠目标的关系当成不存在的依赖。

源码请求同时核对页面索引中的文件指纹和磁盘内容；其他页面重新扫描后，旧页面也不能混用新源码。界面静态资源在服务启动时固定为私有副本，重新构建界面后须重启本工具进程。

## 分析边界

- Python 包关系采用 Grimp；独立脚本和测试文件保留符号与导入证据，当前不推测其模块目标。
- 前端关系采用 dependency-cruiser，支持 TypeScript、JavaScript、Vue script、别名及类型导入；Vue 模板不提供完整调用图。
- 动态表达式、无法静态定位的引用及解析失败会明确展示。测试与生成文件可以浏览，但不是业务质量分数的替代指标。
- 排除 Git 内部文件、依赖目录、环境文件、凭据、原始数据和报告产物；拒绝符号链接、越界访问、二进制和超过 1 MiB 的文件。

工具允许通过 `localhost`、回环或局域网 IP 浏览，拒绝外部域名和公网 IP 的 Host；页面发起重新扫描时，Origin 的协议、主机和端口必须与当前请求一致。它不执行被浏览的代码，也没有通过 HTTP 运行测试或任意命令的接口。

## 质量与检查报告

本工具读取外部生成的原生检查报告、覆盖率和 `quality.json`。用 `make architecture CI_REPORT_ROOT=<报告根目录>` 选择要浏览的报告目录，切换到“质量报告”查看函数风险、原生 CI 与已有架构守卫结果，再选择两次报告进行基线比较。公开仓不包含私有部署的本地 runner。

已有原生覆盖率时，可以仅重新关联指标，不重跑测试：

```sh
.venv-architecture/bin/python -m tools.architecture.metrics --root . --ci-run /absolute/report/run
```

Python 使用 Radon 与 coverage.py 的函数可执行行；前端使用 ESLint classic complexity 和 Vitest Istanbul 原始语句映射。CRAP = CC² × (1 − 行覆盖率)³ + CC。可靠的零覆盖记为 0%，缺失或不能可靠映射的覆盖率记为未知，不补零。Vue template/样式不赋函数分数，E2E 通过不折算为函数覆盖率。

模块风险着色按当前报告中的函数最高 CRAP，并显示达到所选阈值数量及有效评估比例。阈值只用于观察，不新增质量门槛；没有全项目总分。源码/检查配置指纹变化会使报告过期，历史报告仍可阅读；不兼容的工具、采集范围或口径不能直接比较，未知不算改善。

现有 portfolio 纯度、私有导入、隐式时间和配置守卫直接取 pytest JUnit 结果。没有原生逐项位置时只展示用例消息，不猜测违规行。原生 HTML 和 trace 通过原工具查看，不嵌入本服务。

“循环依赖”页显示 Grimp/dependency-cruiser 返回的闭环示例及导入行；默认看运行时关系，纯类型与混合关系分开。它不是所有简单循环的穷举，达到查询或数量上限时明确提示截断，也不作为新的 CI 失败条件。基线比较同时展示已有守卫的新增、消失、恶化与改善；跳过、缺失和不兼容结果不会算作改善。

“变异试点”页读取按需运行的原生结果，展示原测试基线、已检出/未检出/超时等状态，并可在源码匹配时进入被测函数。定位为函数入口，不伪造每个变异的精确行。比较要求工具、函数、变异总体与运行依赖兼容；所选测试内容可改进并列明变化，缺失证据不能算改善。浏览器始终只读，不提供运行测试的按钮。
