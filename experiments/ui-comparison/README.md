# 前端组件对照原型

状态：隔离对照与持仓视觉稿已完成，用户已认可风格并授权真实持仓页 Naive UI 试点；用户已确认继续按页面推广与可完全收起侧栏，实施见整体计划第 21 节。此目录没有生产接口、登录凭据、真实账户或持仓数据；保存交易只改变浏览器内存。

三份独立生产构建复现同一组持仓表格与交易表单，统一使用 `shared/model.ts` 合成数据、`shared/Cell.vue` 和项目原有 `frontend/src/utils/helpers.ts`。不是完整产品页面，也不能用它的体积代替全站大小。

## 视觉原型（新增）

用户反馈组件测试页的设计风格不足后，新增 `/design/` 作为完整持仓页视觉稿；原来的三库对照仍用于组件验证。运行 `npm run build:design` 后，在同一静态服务器打开 http://127.0.0.1:4318/design/。

- Naive UI 控件配合暖白画布、暖灰导航、系统宋体标题与无衬线表格，保留原币/CNY、未知报价和价格精度。
- 同一份虚构持仓用于汇总、市场/账户筛选、人民币市值排序、搜索、账户展开、详情与演示报价编辑。搜索只改明细，账户/市场改变摘要；缺价的成本和市值一起排除。
- 桌面侧栏可完全收起，手机采用库的抽屉与持仓卡片；侧栏方案现已获用户确认。其他导航项仅提示当前预览范围，没有伪造未实现页面。
- 不含真实持仓、报价、账户或凭据；仅在内存修改演示报价。未接业务API、转仓、标签和研究任务等完整功能，不能当作正式业务迁移已完成。
- 此页功能与三库测试页不同，不套用旧性能结果。截图在 `results/screenshots/design-*`，9 项针对性检查结果在 `results/design-check.json`；设计决定见整体计划第18节。

## 运行

在本目录执行，Node 使用项目当前的 22.23.0（Nuxt UI 要求至少 20.19 / 22.12）：

```sh
npm ci --ignore-scripts
npm run typecheck
npm run build
npm run serve
```

打开 http://127.0.0.1:4318/，可分别进入 `/element/`、`/naive/`、`/nuxt/`。页面支持 50 / 200 行样本、代码/账户/日期筛选、盈亏排序、账户展开、固定操作列、演示交易校验与取消重开。价格含 0.085、1.409；未知价格和汇率保留为 `—`，真零单独覆盖。

日期过滤针对每条样本的交易日期；不表示正式持仓已新增相同业务筛选。三版均使用普通表格，无虚拟化；名称列至少 240px，其他列固定，总最小宽 996px、可见区域高 560px，窄屏在表格内部横滚。

## 复核

脚本复用主项目 `frontend/node_modules/playwright` 和它的 Chromium。先按项目开发说明安装 frontend 依赖及 Playwright 浏览器，再启动上述静态服务器：

```sh
npm run check
npm run measure
```

`node build-sizes.mjs` 可记录独立构建的 JS/CSS 原始字节、gzip 和资产哈希。

`check.mjs` 驱动真实输入、选择、日期编辑、排序、展开、表单校验、焦点、取消与手机操作；模型快照仅用于断言，未代替控件点击。每项使用独立浏览器上下文。

`measure.mjs` 在同一 Chromium 中串行轮换三版，按 50 / 200 行与冷上下文 / 缓存重访分组。每组先记录并排除一次预热，再统计五次有效测量，保留原始样本与异常。关闭其他构建或浏览器压力任务后执行，避免争抢资源。

- ready 是导航开始到 Vue 挂载并等待两帧的时间，不是完整生产页面的加载承诺。
- 交互计时包含 Vue 更新与两帧等待，不能当作 INP；弹窗不等完整过渡结束，scrollTop 跳转不代表持续滚动 FPS。冷上下文也不等于浏览器进程冷启动。
- 本地静态服务器不压缩资源；Resource Timing 的传输字节与离线 gzip 体积分别报告。
- 暖色、系统字体与共享金融字段相同；保留各库正常交互及最少必要适配，不建跨库通用框架。
- 当前对照不涵盖生产接口、图表、异步标的搜索、文件导入或完整屏幕阅读器审计。

结果与截图写在 `results/`。版本锁定在本目录 `package-lock.json`，主项目的依赖、业务源码和构建不受影响；`node_modules/` 和 `dist/` 不入库。
